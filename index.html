Customs Code Lookup

Built for TecEx — HMRC CDS Volume 3, Appendix 1 & 2

This tool contains procedure codes (DE 1/10) and additional procedure codes (DE 1/11) scraped directly from HMRC's official GOV.UK documentation. It runs entirely in your browser — no backend, no server, no external calls unless you enable the AI feature.

The optional AI layer uses the Claude API to interpret plain English shipment descriptions and map them to the most relevant codes, using the scraped HMRC data as context.
