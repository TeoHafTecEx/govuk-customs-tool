Raw API Query

Write any query using GOV.UK Search API params. One param per line as key=value.

—
Parameter reference
q=search terms
count=1–1500 (default 10)
start=offset for pagination
order=public_timestamp or -public_timestamp
filter_organisations=hm-revenue-customs
filter_format=guidance | publication | detailed_guide
filter_public_timestamp=from:2024-01-01,to:2024-12-31
reject_organisations=organisation-slug
aggregate_organisations=10
aggregate_document_type=10
